### `src/scripts/reveal.ts` (utilitário, event-driven)

**Analog:** próprio arquivo (30 linhas), padrão obrigatório a estender.

```ts
export function initReveal(): void {
  const els = document.querySelectorAll<HTMLElement>('[data-reveal]');
  if (!('IntersectionObserver' in window)) {
    els.forEach((el) => { el.classList.add('is-revealed'); });
    return;
  }
  const io = new IntersectionObserver(
    (entries) => {
      for (const entry of entries) {
        if (entry.isIntersecting) {
          entry.target.classList.add('is-revealed');
          io.unobserve(entry.target);
        }
      }
    },
    { rootMargin: '0px 0px -8% 0px', threshold: 0.08 },
  );
  els.forEach((el) => { io.observe(el); });
  setTimeout(() => {
    els.forEach((el) => { el.classList.add('is-revealed'); });
    io.disconnect();
  }, 2600);
}
```

Manter: fallback sem IO, `unobserve` após disparo, timeout de segurança 2600 ms. Mudar: seletor `[data-r]` (excluir elementos do hero), classe `in`, `threshold: 0` + `rootMargin` negativo para cards altos (Pitfall 5). Adicionar IO para o pai da foto, IO de `.run` nos `.screen`, IO do hero (`.paused` na aurora), IO de seções para `.on` da nav. `base.css` 53-71 (`[data-reveal]`) é substituído por `[data-r]` em `motion.css`, sempre sob `html.js-ready` **e** `@media (prefers-reduced-motion: no-preference)`.

**Fonte:** `scripts/security-check.sh` (check 2) + RESEARCH Pattern 3.
**Aplica a:** todos os `.astro`/`.ts` novos.

**Fonte:** `BaseLayout.astro` 21-23 + `base.css` 53-71.
**Aplica a:** todo estado "escondido".

[data-reveal] { opacity: 1; transform: none; }
