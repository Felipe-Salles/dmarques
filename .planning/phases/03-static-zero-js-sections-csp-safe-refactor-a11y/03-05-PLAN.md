## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Content Collection (YAML validado por Zod em build) -> markup renderizado | dados de conteúdo entram no HTML |
| CSS/markup de seção -> superfície de estilo da CSP da Fase 7 | o que se autora aqui define o que a Fase 7 poderá travar |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-11 | Tampering (XSS) | interpolação de campos de collection no markup | mitigate | Todo campo é interpolado como `{item.data.campo}` (nó de texto, escapado pelo Astro), nunca via `set:html`. Proibido introduzir `set:html` nesta fase; a auditoria de segurança da Fase 2 já registrou P02-003 como Low para escape de campos de case. |
| T-03-01 | Tampering | `ServicesSection.astro`, `ProcessSection.astro` | mitigate | Zero `style=`, zero `<script>`, zero handler inline; ícones são `<svg>` inline sem `href`/`xlink:href` externo. Verificado por `security-check.sh` verificacao 2 e por grep de sintaxe de editor. |
| T-03-12 | Tampering (supply chain) | biblioteca de ícones | mitigate | Proibição explícita de instalar pacote npm de ícones (UI-SPEC "Icon library: none"); os SVGs são portados à mão do design source. Critério de aceite verifica que `package.json` não ganhou dependência. |
| T-03-13 | Information Disclosure | conteúdo das collections | accept | Todo o conteúdo é material de marketing público, sem PII nem dado sensível; não há classificação de dados a proteger nesta superfície. |
</threat_model>
