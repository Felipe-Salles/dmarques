## Decisions Made
- All light-card micro-labels and the form helper text use `var(--color-light-text-muted)` uniformly (not `--color-light-text-faint`), which both satisfies the plan's `grep -c 'color-light-text-faint'` == 0 acceptance criterion and keeps every small text element on the card above 4.5:1 without touching the base token.
- `<label for="...">` is set explicitly on every contact field's wrapping `<label>` (in addition to it wrapping the `<input>`/`<select>`/`<textarea>`) so the `for`/`id` pairing is textually verifiable by grep, not just implicit via wrapping.
- CtaFinal's radial glow container carries its own `overflow: hidden` (moved off the `<section>` during self-check) so the section itself never clips descendants — consistent with the ContactSection glow and the project's Pitfall 4 guidance.
- SiteFooter's watermark reuses `var(--color-surface)` (`rgba(255,255,255,.045)`) as its text color — the value matches the design's literal watermark opacity exactly, avoiding a new token or hex literal.
