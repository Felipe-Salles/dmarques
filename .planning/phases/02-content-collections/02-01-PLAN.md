## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| repo author → build pipeline | Content files authored in-repo are parsed and typed by `astro sync` at build time. The only input author is the maintainer with repo write access. |
| build output → visitor | Content strings reach a visitor only after Phase 3 renders them. No Phase 2 artifact is served directly. |
| package registry → build | Unchanged from Phase 1. This plan installs nothing. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Tampering | `src/content/*/*.yaml` entries | mitigate | `z.strictObject` on all four schemas with every field required and min-bounded — an unknown key or a missing field aborts `astro sync`, so `pnpm build` and the CI `verify` job fail closed. Proven once by the negative test in plan 02-03. |
