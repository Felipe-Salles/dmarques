| Boundary | Description |
|----------|-------------|
| runtime configuration → repository record | Dashboard-only state exists nowhere else once memory fades |
| security findings → phase closure | An under-recorded finding lets risk pass silently into Phase 2 |
| secrets in the environment → the committed run file | The run file is committed to a public repository |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-08-02 | Repudiation | Undocumented runtime configuration | mitigate | The "Estado de configuração fora do git" section is the explicit record of truth for the Vercel project settings, GitHub branch protection, 2FA status and spend-cap decision (RESEARCH L494-L499) |

| T-08-04 | Information Disclosure | Advisories below the audit threshold going unnoticed | mitigate | Lower-severity `pnpm audit` advisories are recorded as Low/Med findings with an owner and target date rather than silently passing (Pitfall 7) |
| T-08-05 | Tampering | Gabarito drift | mitigate | This plan writes only the run file; `git diff --quiet` asserts `SECURITY-CHECKLIST.md` is unmodified, keeping the template stable for Phases 2-7 |
