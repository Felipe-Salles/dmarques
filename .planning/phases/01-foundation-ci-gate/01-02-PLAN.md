## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| build output → public CDN | Everything in `STATIC_DIR` is world-readable once deployed |
| browser → third-party origins | Any external origin referenced by the page becomes a runtime dependency and a CSP entry |
| repo source → built HTML | Inline styles/scripts in source become inline surface in output |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Information Disclosure | Built assets in `STATIC_DIR` | mitigate | Task 3 greps the whole output tree for `RESEND_API_KEY` and `re_[A-Za-z0-9]{20,}`; the tight regex avoids the minified-identifier false positives of a bare `re_` grep (Pitfall 4) |
| T-02-02 | Tampering | Third-party font origin | mitigate | Fonts served same-origin via the Astro Fonts API; Task 3 asserts zero `fonts.googleapis.com` / `fonts.gstatic.com` references, removing a third-party injection vector and the visitor-IP leak (LGPD) |
| T-02-03 | Tampering | Inline script/style surface | mitigate | `build.inlineStylesheets: 'never'` plus the `grep -c '<style'` = 0 assertion; the analytics script is a bundled module Astro hashes, so it survives the Phase 7 strict `script-src 'self'` without `unsafe-inline` |
| T-02-04 | Elevation of Privilege | Vercel function surface | mitigate | Function count asserted `<= 1` (actual: 0). No `src/pages/api/*` stub is created (Pitfall 1) |
| T-02-05 | Information Disclosure | Analytics beacon | accept | Vercel Web Analytics is cookieless and same-origin (`/_vercel/insights/*`); no new origin, no persistent identifier, no consent banner required (D-06). DevTools cookie verification is a Phase 5 checklist item |
| T-02-06 | Denial of Service | Page weight / render | mitigate | Only two font files preloaded, zero images, zero motion; the JS-weight and Lighthouse gates in plans 03/04 enforce the budget continuously |
