## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| estado do browser (viewport, núcleos, data-saver) -> lógica de cliente | entrada não controlada pelo site, lida como hint, nunca como dado confiável |
| árvore de dependências -> bundle servido | qualquer pacote novo viraria código executado no cliente |
| repositório -> pipeline de CI | um passo de CI a mais é superfície de execução automatizada |
