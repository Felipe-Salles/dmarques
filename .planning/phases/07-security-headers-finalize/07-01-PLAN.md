## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Internet browser -> Vercel edge | Every response (HTML, assets, 404, Function) crosses here; headers are the browser-side policy |
| GitHub Actions -> protected preview | Bypass secret crosses into CI logs/requests |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-01 | Spoofing | TLS downgrade / SSL strip | mitigate | HSTS max-age=63072000 includeSubDomains preload in vercel.json on /(.*); asserted by checkNonCspHeaders offline and live |
| T-07-02 | Tampering | Clickjacking | mitigate | X-Frame-Options DENY now; CSP frame-ancestors 'none' follows in 07-02 |
| T-07-03 | Tampering | MIME sniffing of assets | mitigate | X-Content-Type-Options nosniff on every path, asserted for the /_astro asset |
| T-07-04 | Information disclosure | Cross-origin leaks | mitigate | COOP same-origin, CORP same-site, Referrer-Policy strict-origin-when-cross-origin |
| T-07-05 | Information disclosure | Bypass secret in CI | mitigate | Secret only via `${{ secrets.VERCEL_AUTOMATION_BYPASS_SECRET }}` env; never echoed; header-gates never prints request headers |
| T-07-06 | Denial of service | Probe traffic vs WAF api-flood | accept | One API request per run (< 10/60 s limit); WAF-mitigated response handled as AVISO, not as a header failure |
| T-07-07 | Tampering | Headers silently not applied by platform (A2) | mitigate | Preview probe in Task 3 records PROBE_RESULT; fallback injection planned in 07-02 |
