# Sketch Manifest

## Design Direction
Direção 6 — "Atmosfera / Aurora técnica": um ambiente escuro com profundidade e luz, como olhar
para dentro de uma tela premium. Fundo #070A14, aurora estática nas cores da logo nova
(#00C8FF → #3A5BFF → #0E1E5B), um único ponto de calor #FF6A3D por tela, painéis de vidro com
granulação (2–3 no máximo), bento com os sites reais rodando em moldura de navegador, tilt leve
no hover, Sora (títulos) + Inter Tight (texto). Fuga deliberada do minimalismo, sem exagero:
riqueza vem de luz, profundidade e prova de trabalho, não de decoração.

## Reference Points
Propostas 1–6 geradas com UI UX Pro Max (estilos Aurora UI + Bento Grid); paleta derivada da logo nova.
