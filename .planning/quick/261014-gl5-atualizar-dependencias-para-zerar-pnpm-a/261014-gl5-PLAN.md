# Quick 261014-gl5: Atualizar dependências para zerar `pnpm audit` (high/critical)

## Contexto

Em 2026-10-14 o `pnpm audit --audit-level=high` voltou a falhar sem que a árvore de
dependências tivesse mudado (advisories novos). Bloqueia o job `verify` do CI.

| Pacote | Versão | Correção | Origem |
|---|---|---|---|
| proxy-addr (critical) | 2.0.7 | ≥2.0.8 | dev (@lhci/cli → express) |
| devalue | 5.9.2 | ≥5.9.3 | astro |
| sharp | 0.35.4 | ≥0.35.5 | astro + devDependency direta |
| brace-expansion | 1.1.18 / 5.0.9 | ≥1.1.20 / ≥5.0.11 | dev / astro |
| basic-ftp | 5.3.1 | ≥6.2.1 | dev (@lhci/cli → puppeteer → proxy-agent) |
| http-cache-semantics | 4.2.0 | ≥4.2.1 | astro |
| source-map-js | 1.2.1 | ≥1.2.2 | astro |
| compression | 1.8.1 | ≥1.8.2 | dev (@lhci/cli) |

## Tarefas

1. Bumps de patch das diretas (pins exatos, padrão do projeto): `astro` 7.3.8,
   `@astrojs/vercel` 11.0.14, `sharp` 0.35.5. Nada de majors (TypeScript 7,
   prettier-plugin-astro 1.x ficam fora).
2. Atualizar transitivas dentro do range (`pnpm update <pkgs>`).
3. O que não resolver dentro do range → `overrides` pontuais em
   `pnpm-workspace.yaml` (ex.: `basic-ftp`, que exige major 6, caminho só de CI).
4. Validar: `pnpm audit --audit-level=high` exit 0, `astro check`, `pnpm test`,
   `pnpm build`, `js-weight-check.sh`, `security-check.sh`.
